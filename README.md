# Tanishka Bindal - Personal Portfolio Website

A modern, responsive, and student-focused personal portfolio website designed for **Tanishka Bindal**, a first-year B.Tech Computer Science and Engineering student at **JECRC University, Jaipur**.

---

## 🌟 Features Included

- **Modern Glassmorphic Design**: Sleek dark and light mode theme switcher with persistence in `localStorage`.
- **Complete Sections**:
  1. **Home / Hero**: Greeting, dynamic typewriter effect, student code badge, CTAs, and social links.
  2. **About Me**: Student profile, core competencies, and background summary.
  3. **Education**: Interactive timeline with B.Tech CSE at JECRC University (First Year) and Class 12 CBSE (PCM).
  4. **Skills**: Progress-tracked cards for C, Python (Basic), HTML5, CSS3, JavaScript, AI Tools, and Computer Fundamentals.
  5. **Projects**: Authentic early CSE project showcases with clean GitHub and Live View links.
  6. **Certifications & Achievements**: Structured cards for academic milestones and continuous learning.
  7. **Interests**: Visual highlights across Computer Science, AI, Web Development, Programming, and Tech Innovation.
  8. **Career Goals**: Short-term (DSA, Hackathons, Full-Stack) & Long-Term (SDE, AI, Mentorship).
  9. **Contact**: Direct communication cards (Email, Location, GitHub, LinkedIn) and an interactive contact form with instant validation.
- **Mobile Responsive**: Custom hamburger menu drawer with smooth transitions and backdrop blur.
- **Zero Build Overhead**: Built purely with HTML5, CSS3, and Vanilla JavaScript—no node_modules or build step needed.

## 🌐 How to Publish to GitHub Pages for Free

1. Create a new GitHub repository named `portfolio` or `username.github.io`.
2. Push `index.html`, `style.css`, and `script.js` to the repository.
3. Go to **Settings** > **Pages** in your repository.
4. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/` in 1-2 minutes!
